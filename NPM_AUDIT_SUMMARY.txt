HIGH VULNERABILITIES (7 total)
──────────────────────────────

1. tmp <=0.2.5 (HIGH)
   Issue: Symlink attacks + path traversal on temp files
   Via: External editor → Inquirer CLI
   Impact: Dev environment only
   Fix: Phase 1 (update to ^0.2.6)
   Status: Simple update, low risk

2. flatted <=3.4.1 (HIGH)
   Issue: Unbounded recursion DoS + prototype pollution
   Via: import-sort-style-eslint → eslint → file-entry-cache
   Impact: Build/linting only
   Fix: Phase 2 (update import-sort-style-eslint to ^7.0.0)
   Status: Simple update, compatible with current eslint

3. expr-eval ^2.0.2 (HIGH - in production!)
   Issue: Prototype pollution + unrestricted functions
   Via: Direct dependency (math expression evaluation)
   Impact: Used in tracker value parsing
   Fix: Phase 3 (replace with math-expression-evaluator, 2-line change)
   Status: NO official fix; safe replacement available
   Risk Assessment: LOW (input pre-sanitized to math operators only)

4-7. Other High Issues (inquirer, eslint transitive dependencies)
   Fix: Resolved by Phase 2 updates

   Fix: Phase 2 (update to ^5.56.5, patch-level update)
